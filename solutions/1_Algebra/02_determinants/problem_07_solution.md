# Problem 7: Using Properties Instead of Recomputing

## Detailed Step-by-Step Solution
For a $3\times3$ matrix, $\det(cA)=c^3\det A$. Given $\det A=-4$:

$$
\det(2A)=2^3(-4)=-32,\qquad
\det(A^T)=-4,\qquad
\det(A^2)=(-4)^2=16.
$$

Also,
$$\det(-A)=(-1)^3\det A=4.$$

## Verification
The scalar factors use the dimension $3$; transposition preserves determinant, and determinants multiply across matrix products.
