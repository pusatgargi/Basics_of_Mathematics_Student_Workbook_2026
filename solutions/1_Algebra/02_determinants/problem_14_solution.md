# Problem 14: A System of Equations and the Determinant

## Detailed Step-by-Step Solution
The coefficient matrix is $A=\begin{pmatrix}1&2\\k&4\end{pmatrix}$, with
$\det A=4-2k$. There is exactly one solution for every $b$ precisely when
$\det A\ne0$, that is, when $k\ne2$.

At $k=2$, the second row is twice the first. For $b=\begin{pmatrix}1\\2\end{pmatrix}$, the second equation repeats the first, so there are infinitely many solutions. For $b=\begin{pmatrix}1\\3\end{pmatrix}$, the equations require the same left-hand side to equal both $1$ and $3$, so there is no solution.

## Verification
The exceptional value $k=2$ is exactly the value at which the determinant is zero.
