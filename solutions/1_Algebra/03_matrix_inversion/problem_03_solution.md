# Problem 3: When Does the Inverse Not Exist?

## Detailed Step-by-Step Solution
For $A=\begin{pmatrix}2&4\\1&2\end{pmatrix}$,

$$\det A=2\cdot2-4\cdot1=0,$$

so $A$ is singular and has no inverse. Also, its first row is twice its second row, so the rows are linearly dependent. A square matrix with dependent rows is not invertible.

## Verification
Both the determinant test and the row-dependence test show that no inverse exists.
