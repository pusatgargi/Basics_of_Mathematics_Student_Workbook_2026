# Problem 14: A Matrix That Is Its Own Inverse

## Detailed Step-by-Step Solution
If $A^2=I$, then $AA=I$ and $AA=I$ in either order, so by the definition of inverse, $A^{-1}=A$.

For example, take
$$A=\begin{pmatrix}1&0\\0&-1\end{pmatrix},$$
which is neither $I$ nor $-I$. Then

$$A^2=\begin{pmatrix}1&0\\0&1\end{pmatrix}=I.$$

## Verification
$A$ multiplied by itself equals $I$, confirming $A^{-1}=A$.
