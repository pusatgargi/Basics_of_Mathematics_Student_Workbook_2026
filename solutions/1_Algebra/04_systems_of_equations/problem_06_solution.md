# Problem 6: A System with a Parameter

## Detailed Step-by-Step Solution
The first equation says $x+y=2$. The second equation's left side is $a(x+y)$, so consistency requires $2a=4$.

- If $a=2$, the second equation duplicates twice the first, and there are infinitely many solutions: $x+y=2$.
- If $a\ne2$, the equations contradict one another, so there is no solution.

There is no value of $a$ giving exactly one solution.

## Verification
Substituting $x+y=2$ into the second equation yields $2a=4$, which gives precisely these cases.
